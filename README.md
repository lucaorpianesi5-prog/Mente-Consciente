# Mente Consciente

App de gestión de entrenamiento personal (entrenador + portal de alumnos). Un solo `index.html`, datos en Google Sheets, publicada en GitHub Pages.

- `CLAUDE.md` — contexto del proyecto para sesiones de Claude (arquitectura, datos, reglas, cómo probar).
- `PENDIENTES.md` — bugs, features y decisiones abiertas.
- `HISTORIAL.md` — registro de lo ya hecho.
- `apps-script/portal-proxy.gs` — proxy del portal del alumno (se pega a mano en Apps Script).
- `herramientas/arnes.js` — pruebas rápidas con Playwright.
